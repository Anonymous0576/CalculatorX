# Scientific & Engineering Calculator

A sleek, responsive, 3D glassmorphic **Scientific & Engineering Calculator** built with pure HTML5, CSS3, and Vanilla JavaScript. Designed with a modern dark optical UI, it supports standard arithmetic, advanced trigonometric/logarithmic functions, SI unit prefixes, and engineering notation.

## ✨ Features

- **Modern 3D Glassmorphic UI:** Dark theme with ambient radial glows, frosted glass backdrop blur, and tactile 3D button press animations.
- **Scientific Functions:**
  - Trigonometry & Inverse Trigonometry: `sin`, `cos`, `tan`, `sin⁻¹`, `cos⁻¹`, `tan⁻¹`
  - Logarithms & Exponentials: `log` (base 10), `ln` (natural log), `eˣ`, `10ˣ`
  - Powers & Roots: `x²`, `x³`, `xʸ`, `√x`, `∛x`, `1/x`
  - Other Math Utilities: `x!` (factorial up to 170), `|x|` (absolute), `round`, `floor`, `mod`, `%`, `±`
  - Constants: `π`, `π/2`, `π/4`, `e`
- **Engineering & Angle Modes:**
  - **DEG / RAD Toggle:** Switch seamlessly between Degrees and Radians for trigonometric calculations.
  - **ENG Mode:** Toggle between Standard notation and Engineering notation (exponents in multiples of 3).
- **SI Unit Prefixes:** One-click multiplication by standard SI prefixes:
  - `p` ($10^{-12}$), `n` ($10^{-9}$), `µ` ($10^{-6}$), `m` ($10^{-3}$), `k` ($10^{3}$), `M` ($10^{6}$), `G` ($10^{9}$), `T` ($10^{12}$)
- **Full Keyboard Support:** Type numbers and operators directly from your keyboard.
- **Responsive Design:** Adapts cleanly from desktop screens (8-column grid) to mobile viewports (5-column grid).

## ⌨️ Keyboard Shortcuts

| Key | Action |
| :--- | :--- |
| `0` – `9` | Enter digits |
| `.` | Decimal point |
| `+`, `-`, `*`, `/` | Add, Subtract, Multiply, Divide |
| `^` | Power ($x^y$) |
| `%` | Modulo (`mod`) |
| `Enter` or `=` | Calculate result (`=`) |
| `Backspace` | Delete last digit (`DEL`) |
| `Escape` | Clear all (`AC`) |

## 🚀 Getting Started

1. **Direct Browser Open:**
   Simply double-click `index_calc.html` to open it in any modern web browser (Chrome, Edge, Firefox, Safari). No build tools or external dependencies are required.

2. **Using a Local Server (Optional):**
   If you have Node.js installed, you can run:
   ```bash
   npm start
   ```
